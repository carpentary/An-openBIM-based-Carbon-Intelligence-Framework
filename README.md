# An-openBIM-based-Carbon-Intelligence-Framework

The [MSCA-MAS source code and setup guide](msca-mas/README.md) are in `msca-mas/`.
See the accompanying paper for the evaluation and its results.

[Representative reproducibility materials](examples/README.md) include an ontology
subset, three rules, a synthetic IFC model, illustrative CPD/EFD records, an
executable example, and fifteen anonymized queries with ground truths.

See the [data and code availability statement](docs/data-and-code-availability.md)
for the released scope and the materials not included.
