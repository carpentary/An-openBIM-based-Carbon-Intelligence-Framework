# Data and code availability

The repository contains the MAS source, dependency lock file, tests, and a
representative reproducibility package under `examples/`. The latter includes
a S-E-P-R-C ontology subset, three SWRL rules, RDF validation/query files, a
synthetic IFC model, illustrative CPD/EFD records, a small executable
geometry-to-carbon workflow, and fifteen anonymized queries with ground truths
and aggregate reference inputs.

The original project IFC models, geological inputs, full project CKG, source
quota workbooks, and third-party emission factor collections are not
redistributed here. Source project documents require authorization from their
owners, and third-party source redistribution terms have not been cleared for
this repository. The public IFC and CPD/EFD examples use independently
constructed geometry and synthetic numerical values instead.

The deposited query excerpt is not the complete 150-query benchmark. The full
experiment cannot be independently regenerated from this representative
package alone. Numerical examples and component checks must not be reported
as validation of the paper's full evaluation. See the paper for the reported
evaluation scope and results.
